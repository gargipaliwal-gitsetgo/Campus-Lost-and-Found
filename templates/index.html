How It Works

Campus Recovery Protocol

A simple 3-step security process designed to return misplaced property safely.

1

Log or Discover

File a lost report with identifying marks, or browse items handed in across campus facilities.

2

Cross-Verification

Items are cross-referenced by location, date, category, and student registration records.

3

Safe Return

Campus security confirms student credentials and physically hands over the verified item.
